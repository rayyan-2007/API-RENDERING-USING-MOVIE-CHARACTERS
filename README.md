# Game of Thrones Characters Viewer

A JavaScript project that fetches and displays Game of Thrones character information and images from an API. Built with HTML, CSS, and JavaScript to practice API integration, async/await, dynamic rendering, and DOM manipulation.

## Features

- Fetch character data from an API
- Display character images and details
- Search for characters
- Responsive user interface
- Error handling for failed API requests

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API

## What I Learned

- Working with APIs using `fetch()`
- Handling asynchronous operations with `async/await`
- Rendering dynamic content in the DOM
- Managing user interactions
- Handling errors gracefully
